# FPL Manager AI – Android Starter (v0.1.0)

نسخة أولية قابلة للفتح في Android Studio.

## ما الذي تعمل عليه النسخة الحالية؟
- تطبيق Android أصلي باستخدام Kotlin وJetpack Compose.
- واجهة عربية باتجاه RTL.
- اتصال مباشر بواجهة FPL العامة لجلب:
  - اللاعبين والأندية والمراكز والأسعار والنقاط.
  - الجولة الحالية أو القادمة وموعد الإغلاق.
- عرض أعلى 10 لاعبين حسب مجموع نقاط الموسم.
- زر تحديث وإعادة محاولة عند فشل الاتصال.

## فتح المشروع
1. فك ضغط الملف.
2. افتح مجلد `FPLManagerAI_Android` في Android Studio.
3. استخدم JDK 17.
4. اسمح لـ Gradle بمزامنة الاعتماديات.
5. شغّل التطبيق على جهاز Android أو محاكي.

## حدود مهمة
- هذه نسخة تأسيسية وليست المنتج الكامل.
- واجهة FPL المستخدمة عامة لكنها غير موثقة رسمياً من Premier League وقد تتغير أو تفرض قيوداً. وثائق المجتمع تؤكد أنها غير رسمية ولا يوجد ضمان توافق.
- الاتصال المباشر من الهاتف مناسب لإثبات الفكرة فقط. قبل النشر سننقل جلب البيانات إلى Backend مع التخزين المؤقت، حدود للطلبات، سجلات تحديث، والتحقق من تغيّر بنية البيانات.
- لا يوجد بعد تسجيل دخول FPL أو إدارة التشكيلة أو توقع النقاط أو الأخبار أو الإشعارات أو مزامنة مصادر خارجية.
- لا تُخزّن كلمة مرور FPL داخل التطبيق ولا نطلبها. الوصول إلى بيانات الفريق الخاص يحتاج مسار مصادقة آمن ومراجعة منفصلة.

## التقنية
- Kotlin + Jetpack Compose + Material 3
- Retrofit + Gson
- ViewModel + Coroutines
- Min SDK 26 / Target SDK 35

## بنية الملفات
- `MainActivity.kt`: الواجهة العربية ولوحة التحكم.
- `data/FplApi.kt`: واجهة الاتصال.
- `data/FplRepository.kt`: تحويل بيانات FPL إلى نماذج التطبيق.
